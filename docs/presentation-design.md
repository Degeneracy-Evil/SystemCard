# 硬件展示整理

默认输出采用摘要卡，不附带设备、挂载、软件与传感器明细表。完整默认页先呈现机器、
CPU、内存、整盘、物理网卡，再呈现已有的加速器、执行环境和软件摘要。
compact 保留现有四个摘要域与采集范围。选择 section 后展开该域，--sources 保留明确来源。

存储摘要只统计 sysfs 报告的 disk 层，不把分区、md/dm 或虚拟设备容量相加；旧快照
缺少 layer 时只采用已有 NVMe/SSD/HDD 类型，不用名字猜测。disk 是内核暴露的整盘，
不承诺硬件 RAID 后端物理盘数量。网络摘要采用明确 physical 类型或旧快照 PCI 关联，
不把桥、bond、VLAN 和 veth 当作物理网卡；未知类型保留未分类数量。

详细页先给设备概览，再给设备的字段组，拓扑与挂载单列。字段/值表按明确设备列分组，
同一设备不为每个字段重复标题；窄窗口的普通记录隐藏缺失字段，整列缺失时隐藏该列。
硬件配置字段针对整盘与 md/dm 分组；虚拟设备和分区保留概览与拓扑，避免重复显示
继承的 I/O 队列属性。零值和 False 必须保留。原始 snapshot 和 JSON 不删字段，不改变 Sysal 采集规则。

健康摘要将当前告警、寿命估计和历史事件分开，当前告警优先；显示层只分类 C++ 已有
finding 类型，不重新判断硬件阈值。权限不足、工具缺失和低功耗跳过按明确采集原因汇总，
不将缺失报告解释为健康。完整来源观察继续由 --sources 查看。

代码上拆出 storage.py、network.py；model.py 负责选择域与组合摘要。共用少量格式与
表格整理函数，DetailTable 仅增加可选的字段分组列，不引入布局插件或通用规则引擎。
保持 Python 3.6.8 与 Rich 12 兼容，采用实机只读采集、终端预览和打包校验，不新增或
执行本地单元测试；既有界面参考图随预期布局更新。
